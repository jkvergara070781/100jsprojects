## Tip Calculator

Overview: 

In this project, I build a practical tip calculator using HTML, CSS, and JavaScript. The user can enter a bill amount and tip percentage, then calculate the final total with one click. It can also reset to zero the bill amount, tip percentage and the total amount with the reset button. It’s a small project, but it gives a really good understanding of how JavaScript takes user input, performs a calculation, and displays the result on the page.
